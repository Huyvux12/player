# Security

Please report security problems by email to **admin@livliv.ai**, not in a public issue. Say what you found, how to
reproduce it (a model file that shows it is best) and which version you used. We will reply by email and tell you when
a fix is released. Please give us a reasonable time to fix it before you make it public.

What counts: anything a model package (`.livliv`, `model.json`, its images, keyforms), a PNGTuber's pictures or a VRM
can make the player do beyond drawing a character or refusing the file: run code, read or send data, reach outside the
package, or hang or crash the page past the limits in [API.md](API.md#untrusted-files).

Supported: the latest release.
